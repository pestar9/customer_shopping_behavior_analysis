# Customer Shopping Behavior Analysis

## Project Overview

This project analyzes **customer shopping behavior** to uncover patterns in purchasing habits, customer demographics, and spending trends. The goal is to transform raw transactional data into meaningful insights that can support **data-driven business decisions**.

The workflow covers the entire data analytics pipeline including **data cleaning, database analysis, visualization, and stakeholder reporting**.

By integrating **Python, PostgreSQL, and Power BI**, this project demonstrates how data can be transformed into actionable insights for improving customer engagement, marketing strategies, and sales performance.

---

## Objectives

* Clean and prepare raw customer shopping data.
* Identify patterns in customer purchasing behavior.
* Answer key business questions related to sales and customer segments.
* Create interactive dashboards for business stakeholders.
* Present insights through a clear and structured report.
